# One Line, One Chill

make.fun bounty entry: one line of horror, a single sentence under 200 characters meant to frighten a reader in one breath.

The entry program is `main.ts` (Node 22, standard library only). It writes the line to `/output/entry.txt` and verifies it with a round-trip read-back check.
